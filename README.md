# Personal Expense Tracker System 📊

A responsive web application designed to help users track, manage, and analyze daily personal expenses efficiently[cite: 1]. Built as part of the AICT Lab project at University of Engineering and Technology (UET), Lahore[cite: 1].

---

## 🌟 Key Features

- **Interactive Dashboard:** Real-time summary cards (Total Expenses, Monthly Spend, Top Category, Daily Average)[cite: 1].
- **Full Expense CRUD:** Add, update, view, and delete daily expense records seamlessly[cite: 1].
- **Visual Analytics:** Dynamic pie charts for category distribution and bar/line charts for spending trends via **Chart.js**[cite: 1].
- **Custom Reports:** Filterable weekly and monthly financial reports[cite: 1].
- **Real-Time Search:** Instant filtering across recorded expenses[cite: 1].
- **Data Persistence:** Uses Browser **LocalStorage API** to save data locally[cite: 1].
- **Responsive Layout:** Optimized for mobile, tablet, and desktop views[cite: 1].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox & Grid), Vanilla JavaScript (ES6+)[cite: 1]
- **Data Visualization:** Chart.js[cite: 1]
- **Icons:** Font Awesome 6.4.0[cite: 1]
- **Storage:** Browser LocalStorage API[cite: 1]
